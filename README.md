# 📊 Stock Market Analysis

## Project Overview
This project analyzes stock market data of Apple, Microsoft,
Netflix, and Google using live data from Yahoo Finance API.

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Yahoo Finance API (yfinance)
- Google Colab

## Key Analysis
- Exploratory Data Analysis (EDA)
- Moving Average Trend Analysis
- Volatility Analysis
- Correlation Analysis
- Machine Learning (Linear Regression)

## Dataset
Live stock data fetched using Yahoo Finance API.
